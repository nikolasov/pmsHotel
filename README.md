## 1. ОБЩИЕ ПРИНЦИПЫ ДИЗАЙНА

### 1.1. Ключевые принципы

| Принцип | Реализация |
| :--- | :--- |
| **Информация на первом экране** | Ключевые данные (шахматка, дашборд) сразу видны |
| **Минимум кликов** | Частые действия — 1-2 клика максимум |
| **Контекстная помощь** | Подсказки, тултипы, всплывающие справки |
| **Обратимость действий** | Возможность отменить/исправить (Undo/Redo) |
| **Визуальная обратная связь** | Анимации, индикаторы загрузки, подтверждения |
| **Доступность** | Цветовая схема для дальтоников, горячие клавиши |
| **Конвергентность** | Единый визуальный язык на десктопе и мобильном |
| **Прогрессивное раскрытие** | Сложные функции скрыты до востребованности |
| **Автоматизация рутинных задач** | Автоматическое выселение, автоматический перевод номеров в уборку |

### 1.2. Целевая аудитория

| Роль | Основные задачи | Частота использования |
| :--- | :--- | :--- |
| **Администратор** | Шахматка, заселение, договоры, продление | Постоянно (8+ часов в день) |
| **Бухгалтер** | Отчёты, оплаты, финансовые данные | Ежедневно |
| **Владелец** | Дашборд, статистика, отчёты | Периодически |
| **Водитель** | Задания, контакты гостей | По мере заданий |
| **Горничная** (будущее) | Статусы уборки | По мере заданий |

### 1.3. Приоритет экранов

1. **Шахматка** — главный рабочий инструмент администратора
2. **Дашборд** — стартовый экран, оперативная информация
3. **Быстрое бронирование** (десктоп и мобильное) — критично для быстрой работы
4. **Задания водителя** — специфичный, но важный сценарий

**Верхняя панель шахматки:**
- Навигация по датам: ◀ Предыдущий | Текущая дата | Следующий ▶
- Переключатель масштаба: День | Неделя | Месяц | Квартал
- Кнопка "Сегодня" — быстрый переход к текущей дате
- Кнопка "📅 Быстрая бронь" — открытие диалога быстрого бронирования

  - По категории номеров

  - По этажу

**Левая панель (список номеров):**
- Закреплённая (не скроллится горизонтально)

  - Категория (мелко)
  - Базовая цена (мелко)
  - Индикатор статуса уборки (цветная точка)
- Сортировка: по номеру / по категории / по статусу

**Центральная область (календарная сетка):**
- Горизонтальный скролл по датам
- Вертикальный скролл по номерам
- Каждая ячейка = 1 день × 1 номер
- Размер ячейки зависит от масштаба

## 7. АДАПТИВНОСТЬ И ДОСТУПНОСТЬ

### 7.1. Цветовая схема для дальтоников

**Принципы:**
- Цвет не единственный носитель информации
- Для разных статусов используются паттерны (штриховка, точки, линии)
- Контрастность текста и фона соответствует WCAG 2.1 AA (минимум 4.5:1)
- Важные действия дублируются иконками и текстом

**Пример:**
- Занят, оплачен — зелёный + ✓
- Занят, частично оплачен — жёлтый + диагональные линии + ⚠
- Занят, не оплачен — красный + крест + ✗
- Требует уборки — оранжевый + волны + 🧹
- Скоро авто-выселение — бирюзовый + часы + ⏰

### 7.2. Поддержка клавиатуры

- Все действия доступны с клавиатуры
- Логичный порядок Tab-навигации
- Видимый фокус на активном элементе
- Поддержка скринридеров (ARIA-атрибуты)

### 7.3. Адаптивность десктопа

**Размеры окон:**

| Размер | Ширина | Адаптация |
| :--- | :--- | :--- |
| Минимальный | 1024px | Все функции доступны |
| Оптимальный | 1280-1920px | Стандартный вид |
| Широкий | 1920px+ | Увеличенные отступы, больше информации |

### 7.4. Локализация

**Поддерживаемые языки (перспектива):**
- Русский (основной)
- Английский
- (Другие языки — по требованию)

**Принципы:**
- Все строки вынесены в файлы локализации
- Поддержка RTL (арабский, иврит) — в перспективе
- Форматы дат, чисел, валют — согласно локали
